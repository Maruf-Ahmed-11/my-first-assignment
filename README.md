# DEVCONF 2026

## Short Description
DEVCONF 2026 is a modern, responsive developer conference landing page designed to showcase the premier tech conference for engineers, founders, and builders. It highlights event details, featured industry speakers, ticket pricing packages, and essential attendee information.

## Live URI
- **Live Demo:** [https://maruf-ahmed-11.github.io/my-first-assignment/](https://maruf-ahmed-11.github.io/my-first-assignment/)

## Used Tech Stack
- **HTML5:** Semantic structure and layout
- **CSS3:** Custom styles, responsive layout, and modern UI components
- **Google Fonts:** Typography powered by the *Inter* font family
- **Font Awesome:** Scalable vector icons for navigation and social links

## Key Features
- **Header & Navigation:** Clean navbar with branding, navigational links, and a "Register Now" action button.
- **Hero Section:** Engaging headline and event introduction designed to drive registrations.
- **Speaker Showcase:** Visual speaker cards highlighting key industry figures and their talk categories.
- **Tiered Pricing Tables:** Clear breakdown of Standard, Pro, and Team conference passes.
- **Interactive FAQ:** Expandable accordion section built with semantic `<details>` and `<summary>` elements.
- **Social & Footer Links:** Integrated social media links, copyright notice, and policy shortcuts.
